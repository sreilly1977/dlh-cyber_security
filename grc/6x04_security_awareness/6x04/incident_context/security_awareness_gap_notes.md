# Security Awareness Gap Notes

**Prepared by:** IT Security and HR  
**Date:** 2026-04-18  
**Classification:** Confidential

## Current Program State

MedDefense has an annual training module, but it is compliance-oriented and does not measure whether employee behavior improves under realistic attack pressure.

## Existing Training Coverage

| Topic | Current Coverage | Gap |
|---|---|---|
| HIPAA basics | Annual module | Does not address phishing decisions |
| Password hygiene | Annual module | Does not address SSO/MFA lures |
| Phishing recognition | Short slide section | Generic examples, not healthcare workflows |
| Reporting suspicious email | Mentioned | No demonstration of Outlook report button |
| Remote work security | Optional module | Not tied to personal cloud or home WiFi behaviors |
| Insider threat awareness | Not formalized | Managers lack safe escalation model |

## Program Gaps

1. No phishing simulation campaign.
2. No click/report behavioral baseline before incident.
3. No role-based guidance.
4. No post-click microtraining.
5. No vishing simulation or phone verification guidance.
6. No documented ethics framework.
7. No HR-approved escalation model.
8. No annual calendar aligned to clinical constraints.
9. No board-level metrics dashboard.

## Constraints

- Clinical staff already complete 14 mandatory modules.
- Training must be short and workflow-specific.
- Simulation results must not be punitive.
- Managers should receive aggregate data unless HR escalation criteria are met.
- No new clinical training during Joint Commission window or flu-season peak.
