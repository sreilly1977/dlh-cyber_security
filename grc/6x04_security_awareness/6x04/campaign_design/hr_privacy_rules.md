# HR Privacy Rules for Security Simulations

**Owner:** HR Director Maria Santos  
**Applies to:** phishing simulations, vishing exercises, post-click training, reporting metrics  
**Classification:** Confidential

## Core Principle

Security simulations are training tools, not employee discipline tools. The program exists to reduce organizational risk by improving behavior, not to shame individuals.

## Individual Data Handling

| Data Type | Who Can See | Notes |
|---|---|---|
| Individual click event | Security awareness program manager only | Used for training assignment |
| Individual report event | Security awareness program manager and SOC metrics | Used to provide positive reinforcement |
| Repeat-click status | Program manager and HR only after threshold | Not shared with manager until formal trigger |
| Department trend | Department manager | Aggregate only |
| Executive summary | CISO and board | Aggregated only |

## Manager Reporting Rule

Managers receive aggregate team data only. Individual click results are not shared with department managers unless:

1. the employee clicks in two consecutive simulation waves, and
2. the employee does not complete assigned microtraining, and
3. HR confirms the escalation trigger, and
4. the purpose is coaching, not discipline.

## Performance Review Boundary

Simulation results must not appear in performance reviews. They may not be used for promotion, compensation, termination or disciplinary decisions unless a separate misconduct process is triggered by non-simulation behavior.

## Employee Communication

Employees must be told:

- simulations are part of training
- individual results are protected
- reporting is encouraged
- clicking is not the end of the process
- reporting after clicking is still valuable

## Distress or Concern Support

If an employee becomes distressed after a simulation, the landing page and microtraining should provide:

- non-shaming language
- reassurance that the event is training
- manager-neutral support path
- HR contact for concern escalation
- no public naming

## Data Retention

Individual simulation data should be retained for 18 months for trend analysis, then aggregated or deleted unless needed for an active HR-reviewed coaching process.
