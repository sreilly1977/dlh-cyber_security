# Vishing Facilitator Notes

## Purpose

Support safe live vishing simulations and tabletop exercises.

## Facilitator Rules

- Do not request or record actual passwords.
- Stop the scenario before a real secret is disclosed.
- Do not impersonate emergency medical staff during real patient-care events.
- Use approved internal names only where authorized.
- Document behavior, not personality.
- Debrief immediately.

## Required Scenario Structure

Each scenario must include:

- scenario ID
- target role
- attack objective
- psychological mechanisms
- success criteria
- caller script
- compliance branch
- hesitation branch
- verification request branch
- assessment rubric
- debrief notes

## Safe Pass Behaviors

A full pass generally includes:

- does not disclose password or MFA code
- refuses unverified remote access
- uses known callback path
- reports the suspicious call
- documents caller name/number/request
- escalates to supervisor or security when appropriate

## Debrief Tone

Use:

- "The attacker used urgency and authority."
- "The safe behavior was to verify through a known channel."
- "You can slow down a request without being unhelpful."

Avoid:

- "You almost caused a breach."
- "That was wrong."
- "This should have been obvious."
